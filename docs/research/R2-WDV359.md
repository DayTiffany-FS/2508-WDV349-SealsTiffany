## Sub-Topic 2 - A/B Testing
What A/B Testing is and what it's purpose is. 

* A/B testing, or split testing, compares two or more versions of a digital asset to see which performs better.
* Helps make data-driven decisions, improves user experience, and continuously optimizes products and marketing.
* Most common tests are for UI design, landing pages, navigation, checkout flows, and pricing/offers.
* Success is primarly measured by conversion rate but also by click-through rate, revenue per visitor, bounce rate, time on page, and retention.

<br>

## Sub-Topic 3 - Use Cases And Testing
This explains what a use case is. It also epxlains who uses them and how to use them. 

* Use case describes how a user interacts with something to achieve a goal. It verifies that users can complete tasks from start to finish using the system in front of them.
* Use cases help developers with design and features, testers to create tests, and stakeholders to understand the system behavior and requirements.
*  These allow for detection of gaps in requirements, validation of real user behavior, improving system accuracy and efficiency, and helping catch defects in the workflow.
