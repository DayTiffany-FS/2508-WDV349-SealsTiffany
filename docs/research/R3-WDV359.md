## Sub-Topic 1 - SWOT Analysis
What SWOT analysis is and how it helps a project. 

* SWOT analysis is a strategic planning framework that is used to evaluate the strengths, weaknesses, opportunities, and threats of something.
* S = Strengths, the things that are done well or the advantages it has. (Positive internal)
* W = Weaknesses, areas that are lacking, needed to improve and avoid downfalls with goals. (Negative internal)
* O = Opportunities, external factors that are favorable to capitalize on. (Positive external)
* T = Threats, external risks that can harm performance. (Negative external)
* How to do: define a goal, gather data and feedback, brainstorm and list items for each part, review and refine, turn insights into strategy.

## Sub-Topic 2 - OWASP Top 10 criticial security risks to web application
A list of the major security risks that is regularly updated using real data. This helps to secure coding and web apps. 

* Broken Access Control - users are able to access data/actions that they shouldn't
* Cryptographic Failures - weak or missing encryption that exposes sensitive data
* Injection - a malicious input executes unintended commands
* Insecure Design - security is not considered during the system design
* Security Misconfiguration - incorrect settings, default credentials, open cloud storage, etc
* Vulnerable and Outdated Components - using libraries with known flaws
* Identification and Authentication Failures - weak login/session management
* Software and Data Integrity Failures - untrusted updates, insecure CI/CD, deserialization issues
* Security Logging and Monitoring Failures - attacks go undetected because of poor logging
* Server-Side Request Forgery (SSRF) - server makes unauthorized internal/external requests

## Sub-Topic 3 - CodeQL
An overview of GitHub's CodeQL and how to use it. 

* CodeQL is a static code analysis engine that is used to scan code. It finds security vulnerabilities and coding errors and shows the results inside GitHub.
* CodeQL treats code like data and analyzes it using queries.
* Supports several coding languages including JavaScript/TypeScript,Python, Java/Kotlin, C/C++, C#, Go, Ruby, Swift, Rust
* Helps find problems early in development

## Sub-Topic 4 - DMCA

An overview of what DMCA is and what it covers.

* DMCA stands for Digital Millenium Copyright Act
* It's a copyright law passed in 1998 with two major parts
* Part 1: Anti-circumvention rules. This makes it illegal to bypass digital locks and create/share tools that bypass these digital locks.
* Part 1 was intended to stop piracy but has had little impact on it. Ends up harming those trying to do legal purposes like research or device repair.
* Part 2: Safe Harbor Rules. This protects websites and online services from being sued for copyright infringement caused by their users as long as they are following notice-and-takedown procedures and removing infringing content when notified.
* Part 2 protections are necessary to the modern internet to allow platforms that host user content to operate without liability risks.
* Exemptions to DRM circumvention are reviewed and updated every three years.
