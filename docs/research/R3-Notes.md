## Topic - Design Practices

This document contains general notes related to design.

<br>

## Sub-Topic 1 - Bad design practices
Practices that should be avoided when designing a site: 

* Don't manipulate the consumer.  
* Don't overcrowd the layout.  
* Don't make your layout sloppy.  
* Be careful with color choice.  
* Don't use too many decorative visuals.  
* Use a clear font style.   

<br>

## Sub-Topic 2 - Design psychology
Psychological tricks that help creators build the right kind of interface 

* Be visually attractive  
* Don't have too many options  
* Memory is limited to a number of objects in a given time  
* Using the psychology makes it more user-friendly

<br>

## Sub-Topic 3 - Good design
What makes a site more user-friendly 

* Make the flow clear  
* Make the brand obvious  
* Have engaging data
